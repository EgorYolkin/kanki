# Roadmap Ledger — `tasks/`

## Rules

- `plan.md` describes the eight-stage plan and dependencies; change scope only with an
  issue and cross-check the stage issues.
- `todo.md` is an acceptance ledger: tick an item **only** after the verification in the
  stage issue actually passed, and keep the note about what is still missing.
- Never present planned behaviour as implemented; a blocked stage stays unchecked with the
  reason.
- Russian prose, links to GitHub issues, no personal notes, no secrets.
- Keep `./scripts/lint.sh markdown` green.
